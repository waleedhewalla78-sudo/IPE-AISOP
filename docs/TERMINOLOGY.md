# Terminology standards (STREAM-6.3)

| Prefer | Avoid |
|--------|--------|
| **Work Center** | workstation, work station, WC alone in UI copy |
| **MO** | Manufacturing Order (except first mention / tooltips) |
| Percentages | no decimals when ≥50%; one decimal when &lt;50% (`formatPercent`) |
| Dates | `DD MMM YYYY` via `<DateCell>` / `dd MMM yyyy` |

Demo path UI components use these conventions.
